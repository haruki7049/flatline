# プロジェクト仕様書：極薄・完全ローカル型「無感情Voice-to-Voice」インターフェース

## 1. プロジェクト概要・思想
* **目的**: 感情表現や過剰な抑揚（ピッチ変動）を物理的に排除し、無機質かつフラットなトーンで事実のみを返答する「ターミナル的」音声対話システムを構築する。
* **基本思想**:
  * **ブラックボックスの排除**: 外部クラウドAPIや肥大化したPythonフレームワークに依存せず、C/Zigによる単一バイナリ・低レイヤー制御で組む。
  * **完全ローカル推論**: 思考から音声生成までを手元PCの閉じた環境（CPU動作可能）で完結させる。
  * **薄い設計**: ゼロコピー（mmap）や静的メモリ確保を前提とし、不要な抽象化層を挟まない。

---

## 2. システムアーキテクチャ

```
[マイク入力 (生PCM 16/24kHz)]
       │
       ▼ (1) Audio I/O
[リングバッファ (固定メモリ)]
       │
       ▼ (2) Audio Codec Encoder (1D-CNN + RVQ)
[ユーザー側離散音声トークン列]
       │
       ▼ (3) Dual-Stream Autoregressive Model (1Bクラス LLM)
[アシスタント側離散音声トークン列]
       │
       ▼ (4) トークン改変レイヤー (無感情化・クランプ処理) ★核心部
[フラット化された音声トークン列]
       │
       ▼ (5) Audio Codec Decoder (RVQ + ConvTranspose1D)
[再生用PCMバッファ]
       │
       ▼ (6) Audio I/O
[スピーカー出力]
```

## 3. コア技術要素とメカニズム

### 3.1 RVQ (Residual Vector Quantization: 残差ベクトル量子化)
* **役割**: 音声特徴ベクトルを、損失を最小限に抑えつつ多段の整数インデックス列（トークン）へと圧縮・離散化する。
* **構造**: K 段のコードブック（辞書）を用意し、各段で「残差（近似誤差）」を逐次的に量子化する。
* **デコードの薄さ**: トークンIDに対応する辞書内ベクトルを段数分足し合わせるだけの配列走査・加算処理。

### 3.2 無感情化（Monotone Control）の介入ロジック
* **トークンの役割分担**:
  * **上位段（Stage 0〜1）**: 音素・言語情報（何を喋っているか）
  * **下位段（Stage 2〜7）**: ピッチ、抑揚、話速、感情表現（どう喋っているか）
* **制御方法**:
  * デコード直前に、Stage 2〜7 のトークンIDを固定値（0や中心値）に強制クランプする。
  * 発話内容の明瞭度を保ちながら、音響的な抑揚・ピッチ変動を物理的に消去する。

### 3.3 軽量推論・CPU駆動の実現手法
* **モデルサイズ**: 7B規模を避け、1B〜2Bクラスの極小モデルを採用（メモリ転送量の削減）。
* **INT4/INT8量子化**:
  * 重みを4bit/8bitブロック量子化に落とし、モデルサイズを500MB〜1GB程度へ圧縮。
  * CPUのメモリ帯域制約（50GB/s〜）下でも、音声フレーム周期（約80ms）以内の推論を可能にする。

## 4. 実装スタック・ファイル構成案 (Zig)

* **言語**: Zig
* **外部依存**: miniaudio.h（OSオーディオ抽象化用の単一ヘッダのみ）
* **重みフォーマット**: SafeTensors (.safetensors)
  * mmap を用いて重みバイナリを仮想メモリ空間へ直接マッピング（ゼロコピー参照）。

```text
src/
├── main.zig          # CLIエントリポイント、推論ループの統括
├── audio.zig         # miniaudio ラッパー (マイク入力 / スピーカー出力)
├── safetensors.zig   # ヘッダJSON解析および mmap ポインタ管理
├── rvq.zig           # RVQエンコード/デコード、音響トークンクランプ処理
├── nn.zig            # Conv1D, ConvTranspose1D, INT4積和演算
└── model.zig         # 自己回帰Transformerループ (KVキャッシュ管理)
```

## 5. 開発ロードマップ

1. **フェーズ 1: SafeTensorsパースとRVQデコードの検証**
   * オープンモデル（EnCodec等）の .safetensors をダウンロード。
   * ヘッダをパースし、コードブックポインタからトークン列をベクトルへ復元する計算をZig単体で通す。
2. **フェーズ 2: 音響改変（脱色）実験**
   * 波形 -> トークン -> トークン改変（下位段クランプ） -> 波形復元のループを構築。
   * 自分の声を通し、実際に平坦な棒読み音声に変換されるかを確認。
3. **フェーズ 3: 思考層（極小LLM）の統合**
   * 1Bクラスの音声トークン対応自己回帰モデルをINT4化して組み込み、単一バイナリによる自律Voice-to-Voice端末を完成させる。
